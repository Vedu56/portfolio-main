RETURN TO PORTFOLIO

PHILLIPS CURVE EVALUATOR

Details of the Project:

• A Python-based economic data analysis project exploring the relationship between inflation and unemployment through the Phillips Curve.
• The program uses data from the Federal Reserve Economic Data (FRED) database, processing unemployment and consumer price index data to calculate year-on-year inflation rates and examine macroeconomic trends over time.
• The project demonstrates how Python can be used to retrieve, clean, transform and analyse economic time-series data.
• Image above shows a visual representation of the US' Phillips Curve from late 1990s to early 2020s using Matplotlib.
