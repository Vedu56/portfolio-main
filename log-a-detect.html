RETURN TO PORTFOLIO

LOG ANOMALY DETECTOR

Details of the Project:

• A Python-based anomaly detection pipeline for identifying unusual behaviour in system authentication logs.
• The project parses semi-structured login logs, aggregates activity by source IP, engineers behavioural and temporal features, and uses an Isolation Forest model to identify anomalous IP behaviour.
• The current synthetic dataset contains 1,000 authentication events across 25 source IPs.
• The project is designed to simulate how security analysts could automatically analyse large volumes of authentication activity and prioritise potentially suspicious behaviour for further investigation.
